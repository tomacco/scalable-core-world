# Claude Code — start here

All rules for working in this repository live in **[AGENTS.md](AGENTS.md)**.
Read it in full before making any change. It is tool-agnostic: the same rules
apply whether you are Claude Code, another coding agent, or a human.

Summary of what you'll find there:

1. What this repository is (a voxel tiny-planet world served by GitHub Pages).
2. The territory rules — which folders you may touch and which you must not.
3. How to settle a new contributor: the interview, the `config.json` schema,
   the manifest, and the personal website.
4. How to verify your work locally before committing.

**Do not modify the engine (`src/`, `index.html`) or another contributor's
folder unless the repository owner explicitly asks you to.**
